# Skills for your AI agent

A **skill** is a reusable set of instructions that helps an agent do a job consistently. Think of it as a work guide: how to plan a change, investigate a problem or check a result.

These skills support consultants building Slice. They are not apps in the launcher, and they do not give an agent access to private records or permission to publish changes.

## Start here

1. Ask your agent to read [AGENTS.md](../AGENTS.md), which sets Slice's rules and teaching style.
2. Choose a collection below. Ask the agent to read its guide and the instructions relevant to your task.
3. Have the agent explain which routine it is using and why, in ordinary business language.

| Collection                                         | How it helps                                                                                        | Start with                                            |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| [Superpowers](https://github.com/obra/superpowers) | Helps an agent clarify the goal, plan manageable steps, investigate problems and verify the outcome | [Using Superpowers with Slice](superpowers/README.md) |

## A prompt you can use

> Read AGENTS.md and skills/superpowers/README.md. Use the relevant Superpowers instructions for this task. Explain the goal and your approach in simple business language. Teach me unfamiliar concepts with short examples. Tell me if a skill is unavailable, and explain what you were able to check before calling the work finished.

## Adding another collection

Add a clearly named folder here with a README explaining the business purpose, when to use it, the original source, the version or dated reference, setup and verification steps, and any limits. Link it in this table and propose the addition in a pull request. Preserve attribution and licensing if copying source material. Keep credentials, personal settings and downloaded tool caches out of this folder.

The repository's permissions, privacy and review rules still apply. Installing a skill does not grant permission to send data to another provider, merge a change or put it online.
