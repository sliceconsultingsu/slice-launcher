# Starter screenshots

These screenshots show the fictional-data learning preview included with the team starter. They contain no real alumni or student records.

- [Desktop](desktop.png): 1440px viewport, complete directory and student examples.
- [Mobile](mobile.png): 390px viewport, stacked cards without horizontal scrolling.

Open the PNG files in a browser or image viewer. To reproduce, run `corepack pnpm team:dev`, open the forwarded preview and capture the same viewport widths. These are sample starter screens, not evidence that matching or database refresh is implemented.
